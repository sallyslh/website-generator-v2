# Restaurant assets (Beit el Zaatar)

Put 5-15 files here (jpg, jpeg, png, webp, svg, pdf):

- a logo named `logo.png` (green and orange) - or any logo image
- photos: the sea-facing terrace, manakish, grills, mezze, the dining room, the old souk entrance
- optionally a PDF menu (`menu.pdf`)
- AT LEAST ONE deliberately bad photo (blurry, tiny or very dark)

Do not add team photos: the pipeline should report them as a gap.

Name the deliberately bad photo starting with `bad-` (for example `bad-dark-room.jpg`), so the automatic check knows it must be rated low.
